# Globe Trek - Discovering Angela

## Windows (the PC that runs the globe)

**[Download the Windows installer](https://github.com/iindiie/AATW-Public-download/raw/main/GlobeTrek-Setup.exe)** (version 1.3.0, about 28 MB)

Run the installer. No admin rights are needed. If Windows SmartScreen appears, choose **More info**, then **Run anyway**, because the installer is not code signed. When Windows asks whether Globe Trek may use the network, allow it on **Private networks** so the phone app can reach it.

SHA-256: `7fc0e1995ca1c37a7216e8ae927304f046247ef4a4f2422443b07a4bea200f55`

## Android (Angela's phone)

**[Download Globe Trek Remote for Android](https://github.com/iindiie/AATW-Public-download/raw/main/GlobeTrekRemote.apk)** (version 1.0.0)

Open the downloaded file on the phone and allow installing from your browser when Android asks. Then, on the PC, press Ctrl+M, open **Mode**, scan the QR code with the phone, and tap **Link the Android app**.
